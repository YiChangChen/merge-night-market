# 夜市合成：內容定稿

這份文件是所有遊戲內文字的唯一來源。`src/game/content/stalls.ts`、`recipes.ts`、`cards.ts` 都從這裡複製文字；程式碼中的 `TODO(content)` 一律對應到本文件的某一節。

> **狀態：已定稿（2026-11-09，Admin 確認）。**配方的材料與階數沿用 GDD M4 表，已經和 `src/game/content.ts` 的品項逐一核對。之後如果要修改文字，先改這份文件，再同步到程式碼；封測期間的調整記錄在下方的「修訂紀錄」。

**阿嬤（提示角色，UX-DR7）：**在夜市逛了一輩子的老客人，每一攤的祖傳吃法她都知道。說話慢慢的、帶台語口氣，例如「憨孫，紅茶配鹽酥雞啦！」
