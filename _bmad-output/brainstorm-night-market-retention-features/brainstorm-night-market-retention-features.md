# 夜市合成：留存功能意圖文件（腦力激盪產出）

> 來源：`.memlog.md`（2026-11-08，partner 模式）。標記：**[使用者決定]** 具約束力；**[教練建議]** 為提案，需求撰寫者可調整。

## 1. 背景與目標

- 目標：讓玩家天天回來（留存），並上架變現。參考 Travel Town: Merge Adventure；主題為台灣夜市。
- 現況：已有 7x8 棋盤合成、5 條合成鏈、12 種客人、同時 3 張訂單、體力／金幣／XP。缺的是棋盤之上的 meta 層「攤位地圖」。

## 2. 核心洞察

- **[使用者洞察]** 上癮核心＝打發時間＋完成一件事後的成就感。
- **[教練建議]** 成就感分層，讓任何時段都有東西可以完成：
  - 秒級：合成
  - 分鐘級：訂單
  - 天級：攤位重建／升級、消化人龍
  - 週級：收藏冊整頁完成（後續擴充）

## 3. 核心循環

**[教練建議，依使用者骨幹整理]**

蓋／升級攤位 → 解鎖合成鏈與發明能力 → 發明新菜 → 用在貴客高價單（及之後的卡牌）→ 賺金幣 → 回頭蓋／升級攤位

- 攤位是遊戲的基本單位，建造和發明互相推動。
- 排隊人龍把攤位實力具體呈現出來，由攤位等級、招牌亮度、招牌菜決定。
- 之後的叫賣秀、YouTuber 爆紅、陣頭表演，本質都是「製造人龍事件」；消化人龍是它們共同的爽感收尾。

## 4. 骨幹（使用者已決定）

### 骨幹 A：攤位建造

**[使用者決定]** 包含三項：
- 消化排隊人龍：把整條人龍服務完的爽感。
- 招牌亮燈：明亮、五顏六色的招牌。
- 攤位升級：從小間升成大間。

需求要點：
- 攤位地圖是新的 meta 層，用訂單賺的金幣重開或升級攤位。**[教練建議]** 題材是「重振沒落的老夜市」，每開一攤就解鎖新合成鏈與新常客。
- 人龍長度要能看出攤位實力；消化人龍要有明確的完成回饋。
- **[使用者決定]** 建攤時可選老闆，老闆決定攤位風格；擺飾由玩家自由決定。（實作可放 MVP 之後，見第 7 節。）
- **[教練建議]** 每個攤位有自己的老闆角色、裝潢風格、專屬合成鏈和小故事，避免攤位長得都一樣；升級時可選外觀分支。

### 骨幹 B：新菜單雙線

**[使用者決定]**
1. 隱藏菜單：先蓋好特定店家，才能在棋盤上自行嘗試跨鏈亂合、碰運氣。成功後，菜單新增一道「老闆發明」。
2. 客人給線索：靠線索解鎖新菜。

需求要點：
- 解鎖發明的前提是已建好某些攤位，把骨幹 B 綁在骨幹 A 上。
- **[使用者決定]** 發明菜的 6 種用途全部保留：
  - 貴客高價單
  - 卡牌
  - YouTuber 爆紅事件
  - 招牌菜欄
  - 每週美食大賽
  - 攤位升級材料
- 其中使用者最心動的三項：
  - 貴客專屬高價單：富豪、藝人、YouTuber 只點發明菜，給大量金幣與鑽石。
  - 發明菜即卡牌：有卡面、故事、星等，重複合成可升星。
  - YouTuber 吃發明菜後拍片爆紅，觸發限時排隊人潮。
- **[教練建議]** 其餘三項的做法：
  - 招牌菜欄：設為招牌後人潮和訂單頻率提升，可更換。
  - 攤位升級材料：小攤升大店需要先上架 N 道發明菜。
  - 每週美食大賽：參賽排名。
- **[教練建議]** 線索有三種載體：
  - 客人台詞
  - 味道文字：例如「怎麼有一股中藥味傳過來」暗示中藥排骨，搭配熱氣動畫
  - 美食接龍：屬於後續擴充
- **[教練建議]** 老闆種類可影響發明成功率，例如年輕創業老闆的發明成功率較高。

## 5. MVP 範圍

**[教練建議，使用者已確認的骨幹]**

納入 MVP：
- 攤位地圖 meta 層：重建與小間升大間、招牌亮燈、排隊人龍呈現與消化。
- 隱藏菜單發明：特定攤位解鎖後可跨鏈合成；成功後菜單新增「老闆發明」。另含客人線索（至少一種載體）。
- 發明菜至少接上一個用途。建議用貴客高價單，讓核心循環能閉合。

明確不在 MVP：
- 卡牌系列
- 節慶活動與陣頭
- 叫賣秀
- 彈珠檯和其他夜市小遊戲
- 美食接龍
- 每日開攤／收攤儀式
- 自由擺飾與選老闆
- 新合成鏈
- 每週美食大賽

## 6. 設計護欄與變現原則

以下每條都由反向腦力激盪翻轉而來。

| 使用者提出的負面情境 | 翻轉後的護欄 |
|---|---|
| 剛開始體力不夠 | **新手開幕週**：前 3 天體力無限或給超大體力池，之後才正常回復 |
| 無預警跳出廣告 | **只用玩家主動選的激勵廣告**（換體力、雙倍收攤紅包），絕不放插頁廣告 |
| 做什麼都要課金 | **課金只賣時間與造型**（招牌外觀、陣頭造型、月卡＝每日領鑽石），不賣過關必需品 |
| 難度太高 | **動態難度**：連續失敗時訂單自動變簡單，並提供「阿嬤幫忙」免費提示 |
| 永遠收集不到最後一張卡 | **卡牌保底**：重複卡轉成星星，可兌換任一缺卡；集卡冊附保底計數器 |
| 節慶活動跟節慶無關 | **節慶取材真實習俗**：例如元宵猜燈謎、中元普渡 |
| 攤販建造雷同、沒個性 | 每攤有獨立老闆、風格與故事（見骨幹 A） |

**[使用者決定]** 請陣頭靠收集碎片或花金幣，盡量不做成硬課金。

## 7. 後續擴充 Backlog

- 卡牌系列：發明菜卡、夜市遊戲卡、招牌卡（全台知名夜市風格）、常客羈絆卡（12 位客人的小故事）、陣頭卡、老闆卡。
- 每日儀式 **[使用者決定採用收攤＋離線上限]**：
  - 開攤：拉鐵捲門，第一位客人是「今日貴人」，獎勵雙倍。
  - 收攤：結算今晚營業額，送紅包袋。
  - 離線營業：離線時自動累積收入，達上限就得回來收。
- 彈珠檯：每日免費抽獎；其他夜市小遊戲（套圈圈、射氣球、撈金魚）用合成產物換代幣。
- 節慶與陣頭：
  - 節慶限定合成鏈與卡牌：年貨大街、元宵、端午、中元、中秋。
  - 週末與節慶人潮變多、獎勵增加。**[使用者]**
  - 請花車或陣頭到店門口表演，表演期間客流 x2，並出現特殊客人。
- 叫賣秀搶單 **[使用者]**：客人舉手，玩家要快速把指定品項交給舉手的人。獎勵依交貨速度從「破盤價→流血價→骨折價」遞減。
  - 叫賣台詞參考：走過路過千萬不要錯過、最後三組、倒數 5-4-3-2-1、要的舉手。
- 美食接龍 **[使用者決定綁合成]**：
  - 題目固定頭尾兩道菜，中間要經過 5~10 道菜。
  - 每道菜都要實際在棋盤合成並出餐；路線跨多個攤位。
  - 獎勵為鑽石或特殊卡。**[教練建議]** 可做每日一題（類似 Wordle），全服同題、可分享。
- 香味線索：高階菜冒出香味煙霧，引來路人；香味範圍隨攤位升級變大。另外高階炸物合成時，油鍋「滋～」聲逐級變大。
- 選老闆與自由擺飾：老闆技能各有差異，例如阿嬤老闆小費多、老師傅做出高階品項的機率高。另可自訂霓虹招牌。
- 新合成鏈：蚵仔煎、章魚燒。

## 8. 待決問題（需求撰寫者需釐清）

1. 攤位與現有 5 條合成鏈怎麼對應：一攤一鏈？MVP 開幾攤？新攤要新增鏈嗎？
2. 攤位地圖與棋盤畫面的關係：分開兩個畫面，還是共用？各自怎麼導覽？
3. 排隊人龍在 UI 上怎麼呈現：和現有 3 張訂單、12 種客人是什麼關係？「消化完」怎麼定義？有沒有長度上限？
4. 招牌亮燈的觸發條件：靠升級、靠發明菜數，還是逐步點亮？
5. 發明配方：MVP 做幾道？跨鏈合成規則是什麼（哪些組合有效）？失敗時要不要消耗資源？
6. 亂合碰運氣和客人線索的比重：有沒有保底，避免玩家一直盲試卡關？
7. 「特定店家」解鎖條件：每道發明綁哪幾個攤位？
8. 經濟數值：
   - 建造與升級成本、金幣產出曲線
   - 貴客高價單的頻率與獎勵
   - 鑽石的取得與用途
   - 現有體力／XP 和新 meta 層怎麼銜接
9. 新手開幕週、激勵廣告點位要不要放進 MVP？
10. 存檔與資料結構：攤位、發明、線索進度的持久化。
